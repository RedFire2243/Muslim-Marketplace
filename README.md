# Muslim Marketplace

Planning documents for a Muslim community marketplace, starting in Central Jersey. The idea is to help people discover useful services, work, mentorship, and opportunities within their local community through natural-language onboarding and relevant recommendations.

**Current phase: documentation only.** These files organize the shared planning conversation. No product code, application scaffold, dependencies, database, or integrations have been added.
